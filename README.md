# LoanLens — Bank Loan Approval Dashboard

A Streamlit + scikit-learn **educational simulation** with a banking-style dashboard, applicant probability simulator, analytics and model insights.

> **Important:** All data and labels are synthetically generated. The model is not validated for actual lending and must not be used to make real credit decisions. No personal customer data is needed.

## Features
- Dashboard overview and interactive Plotly charts
- Applicant inputs with synthetic model approval probability
- Random Forest classifier with reproducible synthetic training data
- Model metrics, feature importance and CSV export

## Run locally
Requires Python 3.10+.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python model.py
streamlit run app.py
```

The app also trains automatically if `loan_model.joblib` is missing. The included model file is generated by `model.py` and should be loaded only from trusted sources.

## GitHub upload
1. Create a GitHub repository, e.g. `bank-loan-approval-dashboard`.
2. Upload `app.py`, `model.py`, `requirements.txt`, `README.md`, `.gitignore` and optionally the generated `loan_model.joblib`.
3. On Streamlit Community Cloud, select your GitHub repository and choose `app.py` as the entry point.

## Limitations
The model learns relationships from a hand-designed synthetic data generator. Its probabilities and performance statistics have no external validation, cannot be interpreted as bank approval odds, and are not suitable for production financial decision-making.
